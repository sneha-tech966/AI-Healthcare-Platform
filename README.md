# MediGuide AI

MediGuide AI is an AI-powered healthcare platform designed to provide intelligent symptom analysis, hospital recommendations, specialist guidance, emergency assistance, and healthcare insights through an interactive user experience.

Features:
- AI symptom assessment
- Risk analysis dashboard
- Hospital recommendation engine
- Emergency support system
- User authentication with Supabase
- Assessment history tracking
- Healthcare analytics dashboard
- Responsive modern UI with Next.js + Tailwind CSS

Tech Stack:
Frontend: Next.js, TypeScript, Tailwind CSS, ShadCN UI  
Backend: Supabase  
Database: PostgreSQL + Row Level Security  
Authentication: Supabase Auth  
Icons: Lucide React
